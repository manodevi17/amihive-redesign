# AmiHive Software Solutions — Enterprise Web Platform

A redesign of the official **AmiHive Software Solutions** website ([amihive.com](https://amihive.com/)) into a **unique, premium enterprise technology platform** inspired by the design languages of **Microsoft** and **Cognizant**.

Built with modern **React 19**, **TypeScript**, **Tailwind CSS v4**, and **Vite 8**.

---

## 🚀 Key Highlights & Enterprise Features

### 1. Microsoft & Cognizant Inspired Enterprise Aesthetic
- **Color Palette**: AmiHive Blue, Orange & White. Blue `#0056D2` / dark `#003A99` / navy `#001A45` / sky `#1FA8F0`, Orange `#FF7A00` / hover `#D94E00` / amber `#FFA533`, on pure white (`#FFFFFF`) and soft `#F8FAFC` surfaces. All tokens live in `src/index.css` under `@theme`.
- **Typography & Precision**: Clean typography hierarchy, subtle tech grid lattice, high-contrast badges, and glassmorphic micro-interactions.
- **Precision Vector Brand Logo**: Custom SVG AmiHive geometric gear-and-hive brand mark with high-DPI clarity.

### 2. Preserved Original Content & Structure (100% Fidelity)
- **All 6 Main Navigation Views**:
  - **Home**: Enterprise hero with digital network sphere, KPI metrics, "What We Do" pillars, full 9-service catalog, interactive technology stack orbit, "Who We Are", "Why Choose Us", "Our Strategic Approach", featured case studies, and client testimonials.
  - **About Us**: Breadcrumb header, "Who We Are", "Our Strategic Approach", "Lead With Innovation. Build Smarter" capability meters (Programming 91%, Design 87%, Animation 72%, Digital Marketing 68%), and 4 enterprise value cards.
  - **Services**: All 9 services (AI Automation, E-commerce, Web Development, Logo & Branding, Static/Dynamic Web Design, SEO, Digital Marketing, Cybersecurity, Mobile App UI/UX) with category filtering and capability breakdowns.
  - **Projects**: Featured Case Study (*Aurora — Collaborative Workspace*), "Empowering Businesses Through Technology" section, and the Project Gallery.
  - **FAQ**: All 6 preserved questions and answers with search filter and expandable accordions.
  - **Contact Us**: Head Office in Marthandam, Tamil Nadu; dual emails (`info@amihive.com`, `amihive007@gmail.com`); Phone & WhatsApp (`+91 83006 11720`); interactive Google Map embed; and functional contact form.
- **Client Testimonials**: StitchCraft Artistry, Pn Granites, Master Foods with interactive carousel.

### 3. Unique Interactive Enterprise Modules
1. **Interactive Project Explorer**:
   - Filter projects across AI, Web, Mobile, IoT, and Marketing.
   - Real-time search by keyword, technology, or client industry.
   - Detailed Case Study Modal with Challenge, Engineering Solution, and Measurable Business Impact.
2. **Smart Service Finder**:
   - 3-step interactive advisor calculating customized service recommendations, tech stacks, deliverables, and estimated delivery timeline.
   - Seamless one-click transfer into the Project Brief Builder or WhatsApp direct consultation.
3. **Enterprise Project Brief Builder**:
   - 4-step scope configurator allowing clients to select project capabilities, architectural integrations, execution tiers, and notes.
   - Real-time generated Enterprise Scope Document with one-click "Copy Spec to Clipboard", direct submission, and WhatsApp dispatch.
4. **Interactive Tech Ecosystem Orbit**:
   - Live technology inspector exploring React, Next.js, Node.js, .NET, Python AI, AWS, Docker, Kubernetes, MongoDB, and PostgreSQL.
5. **Instant WhatsApp Floating Desk**:
   - Pre-composed inquiry presets routing directly to `+91 83006 11720`.

## 🛠️ Tech Stack & Architecture

- **Framework**: React 19
- **Build Tool**: Vite 8
- **Language**: TypeScript 6
- **Styling**: Tailwind CSS v4 (`@tailwindcss/vite`)
- **Icons**: Lucide React + Custom Enterprise Social SVG Suite
- **Deployment**: Zero-backend, frontend-focused, static SPA ready for instant deployment on **Vercel**, **Netlify**, or **Cloudflare Pages**.

## 💻 Local Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Run production build
npm run build

# Preview production build
npm run preview
```

## 🌐 Deploy to Vercel

This repository is optimized for Vercel deployment out of the box:

```bash

```
